# 🏢 AI 产业集群空间服务系统 — 用户产品手册

> **系统版本**: v2.0（统一架构）  
> **最后更新**: 2026-06-06  
> **系统定位**: 面向企业园区/产业基地的一站式空间服务管理平台

---

## 一、系统概述

AI 产业集群空间服务系统是一套面向企业园区的综合性空间服务管理平台，提供**空间资源管理**、**预约调度**、**费用结算**及**余额管理**四大核心能力。系统采用前后端分离架构，支持 Web 端访问，适用于企业内部办公空间、会议空间、餐饮空间、灵活工位等多种场景的数字化管理。

### 核心价值

| 维度 | 说明 |
|------|------|
| 🎯 资源利用率提升 | 实时可见的可用资源，减少空置浪费 |
| ✅ 流程线上化 | 预约→审批→使用→结算，全链路数字化 |
| 💰 成本透明 | 多种定价体系（标准/会员/VIP）统一管理 |
| 📊 数据驱动 | 预约统计、使用趋势、费用分析辅助决策 |

## 三、用户角色体系

系统支持四种用户角色，权限逐层递增：

| 角色 | 标识 | 核心能力 |
|------|------|----------|
| 👤 普通用户 | `user` | 查看资源、创建预约、查看自己的预约和费用 |
| 🏢 办公室管理员 | `office_admin` | 管理本办公室空间资源、审批本办公室预约 |
| 🔧 系统管理员 | `admin` | 管理所有空间资源、审批所有预约、配置系统 |
| ⭐ 超级管理员 | `super_admin` | 所有权限，含删除操作、系统全局配置 |

用户的定价身份（`user_type`）决定了费用计算标准：

| 用户类型 | 定价标准 |
|----------|----------|
| `internal`（内部员工） | 会员价（`member_price`） |
| `member`（注册会员） | 会员价（`member_price`） |
| `vip`（VIP 用户） | VIP 价（`vip_price`） |
| `external`（外部访客） | 标准价（`base_price`） |

## 四、功能模块详解

### 4.1 空间资源管理

#### 空间类型（SpaceType）

空间类型是资源的分类维度，用于定义一类空间的核心配置：

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| `type_code` | 唯一代码标识 | `meeting_room`, `office_desk`, `dining` |
| `min_duration_unit` | 最小预订单位 | `hour`, `half_day`, `day`, `week`, `month`, `meal` |
| `requires_approval` | 是否需要审批 | `true` / `false` |
| `requires_deposit` | 是否需要押金 | `true` / `false` |
| `deposit_percentage` | 押金比例 | `0.0` ~ `1.0` |
| `supported_duration_units` | 支持的预订单位列表 | `["hour", "half_day", "session", "slot", "day", "week", "month", "meal"]` |

#### 空间资源（SpaceResource）

资源是具体的物理空间实例，归属于某一空间类型：

| 配置项 | 说明 |
|--------|------|
| `name` | 名称，如"第一会议室" |
| `location / floor / building` | 位置信息 |
| `capacity` | 容纳人数 |
| `facilities` | 设施清单 |
| `base_price` | 标准价（元/单位） |
| `member_price` | 会员价 |
| `vip_price` | VIP 价 |
| `meal_standard_price / meal_vip_price / meal_luxury_price` | 餐饮专用三档定价 |
| `free_hours_per_month` | 每月免费额度（小时） |
| `price_unit` | 价格单位 |

#### 资源时段（ResourceTimeSlot）

为支持场次/时段预订，资源可配置时段模板：

| 配置项 | 说明 |
|--------|------|
| `slot_key` | 时段标识，如 `morning`, `afternoon` |
| `slot_name` | 时段名称 |
| `start_time / end_time` | 起止时间 |
| `duration_value / duration_unit` | 时长 |
| `max_bookings_per_slot` | 每时段最大预订数 |
| `price_override` | 价格覆盖（可选） |

### 4.2 预约管理（核心功能）

#### 预订单位体系

系统支持 **8 种预订单位**，覆盖不同使用场景：

| 预订单位 | 适用场景 | 所需参数 | 计价方式 |
|----------|----------|----------|----------|
| `hour` | 会议室、工位小时租 | `start_time`, `end_time` | 时长 × 单价 |
| `half_day` | 半天场地租用 | `time_slot_key` | 时段单价 |
| `session` | 分场次活动 | `time_slot_key` | 场次单价 |
| `slot` | 固定时段（如健身房） | `time_slot_key` | 时段单价 |
| `day` | 日租办公室 | `end_date` / `booking_days` | 天数 × 日单价 |
| `week` | 周租工位 | `end_date` / `booking_days` | 周数 × 周单价 |
| `month` | 月租办公室 | `end_date` / `booking_days` | 月数 × 月单价 |
| `meal` | 餐饮包间/餐位 | `meal_session`, `guests_count` | 餐标 × 人数 |

#### 预约状态流转

```
                        ┌──────────┐
                        │  pending  │  ← 待审批（需要审批的类型 或 外部访客）
                        └────┬─────┘
                             │
                ┌────────────┼────────────┐
                ▼            ▼            ▼
          ┌──────────┐ ┌──────────┐ ┌──────────┐
          │ approved │ │ rejected │ │cancelled │
          └────┬─────┘ └──────────┘ └──────────┘
               │
               ▼
          ┌───────────┐
          │ confirmed │  ← 用户确认/支付后生效
          └─────┬─────┘
                │
          ┌───────────┐
          │  active   │  ← 使用中（管理员标记）
          └─────┬─────┘
                │
          ┌───────────┐
          │ completed │  ← 使用完成
          └─────┬─────┘
                │
          ┌───────────┐
          │  settled  │  ← 结算完成
          └───────────┘
```

#### 创建预约流程

1. **选择空间类型** → 2. **选择具体资源** → 3. **选择日期与时段** → 4. **填写预约信息** → 5. **确认费用** → 6. **提交预约**

创建时自动处理：
- **冲突检测**：按预订单位类型（小时/时段/天/餐次）进行碰撞检测
- **费用计算**：根据用户身份定价标准计算总价
- **免费额度抵扣**：小时类预约自动抵扣当月免费额度
- **余额抵扣**：内部员工&会员自动检测余额并优先扣减
- **审批判断**：根据空间类型配置和用户身份决定是否需要审批

### 4.3 审批管理

#### 自动审批

以下情况自动审批通过（状态直接设为 `approved`）：
- 内部员工/会员/VIP 用户预约低价值空间
- 余额可覆盖全部或部分费用时自动审批

#### 人工审批

以下情况进入待审批列表：
- 空间类型配置 `requires_approval = true`
- 外部访客预约（状态设为 `pending`）

审批流程：

```
管理员收到审批通知
      │
      ├── 审批通过 → 预约状态变为 approved
      │                ├── 内部用户：可直接确认使用
      │                └── 外部访客：需线下付费后激活
      │
      ├── 审批拒绝 → 预约状态变为 rejected（附带拒绝原因）
      │
      └── 要求修改 → 通知用户修改后再提交
```

#### 审批与收款一体化

支持特殊的**审批+确认收款**操作路径：
- 管理员可在审批时直接录入线下收款信息
- 同时完成 `approved` + `payment_status → paid` 两个动作
- 适用于外部访客在管理员处付款的场景

### 4.4 支付与结算

系统支持三种记账模式，由用户身份和空间类型共同决定：

#### 记账模式对照表

| 模式 | 名称 | 适用用户 | 说明 |
|------|------|----------|------|
| `credit` | 记账模式 | 内部员工 | 使用后结算，月底统一月度账单 |
| `balance_deduct` | 余额抵扣 | 内部员工/会员 | 创建预约时实时从账户余额扣减 |
| `mixed` | 混合支付 | 余额不足的员工 | 余额抵扣部分 + 记账部分 |
| `prepay` | 预付模式 | 外部访客 | 线下付费后由管理员确认生效 |

#### 费用确认状态

| 状态 | 说明 |
|------|------|
| `none` | 免费使用，无需付费 |
| `pending` | 待支付确认（线下支付） |
| `deposit_paid` | 保证金已登记 |
| `partial` | 部分支付 |
| `paid` | 已全额确认 |
| `refunded` | 已退款 |

#### 结算闭环

```
预约完成 (completed)
      │
      ├── 记账模式 → 记入月度账单 (CreditNote)
      │                └── 管理员月度结算 → settled
      │
      ├── 余额抵扣 → 已完成扣款
      │                └── 无需额外结算 → 直接 settled
      │
      └── 预付模式 → 管理员确认收款 → paid
                           └── 预约完成 → settled
```

### 4.5 余额管理（用户充值余额）

用户余额账户包含三种子余额：

| 余额类型 | 说明 | 使用优先级 |
|----------|------|-----------|
| `membership_balance` | 会员套餐余额 | 优先使用 |
| `service_balance` | 服务充值余额 | 次优先 |
| `gift_balance` | 赠送余额 | 最后使用 |

余额扣减次序严格按照：**会员余额 → 服务余额 → 赠送余额**。

### 4.6 办公室（实体绑定）

办公室是系统的实体组织单位，用于：
- 关联同一物理办公区域的所有空间资源
- 权限隔离：办公室管理员仅能管理本办公室的空间
- 费用归属：预约费用按办公室归类统计

## 五、用户操作指南

### 5.1 普通用户

#### 查看可用资源

1. 进入空间服务首页 → 空间资源列表
2. 可按类型、容量、位置等条件筛选
3. 点击资源卡片查看详情（设施、价格、可用时段）

#### 创建预约

1. 在资源详情页点击"立即预约"
2. 分步操作：
   - **第一步**：选择日期
   - **第二步**：选择时段（系统自动展示可用时段）
   - **第三步**：填写预约信息（主题、人数、备注等）
   - **第四步**：确认费用明细 → 提交
3. 提交后系统显示预约结果（自动通过/待审批）

#### 查看我的预约

- 进入"我的预约"页面，查看所有历史预约记录
- 可按状态筛选（待审批/已批准/已完成/已取消等）
- 可查看预约详情、费用明细

#### 取消预约

- 在预约详情页点击"取消预约"
- 需填写取消原因
- 已抵扣的余额将自动退还

### 5.2 管理员操作

#### 审批管理

1. 进入"审批中心"查看待审批列表
2. 点击预约查看详情（用户信息、空间信息、特殊要求）
3. 操作：审批通过 / 拒绝 / 要求修改
4. 审批通过后可选择不同支付模式

#### 预约管理

- 查看全部预约（按状态、类型、日期等维度筛选）
- 对预约进行：激活（标记开始使用）、完成、结算、取消
- 批量操作：批量删除/审批/取消/完成

#### 资源配置

- 管理空间类型：创建/编辑/启停类型
- 管理空间资源：创建/编辑资源，配置价格、时段、设施
- 配置资源时段模板

#### 结算管理

- 查看记账月度账单
- 处理月度统一结算
- 查看已结算和未结算的预约

## 七、常见场景与操作流程

### 场景一：内部员工预约会议室（自动审批）

```
选择会议室 → 选择日期 → 选择时段 → 填写信息 → 提交
                                                      │
                ┌─────────────────────────────────────┤
                ▼                                     ▼
        余额充足（自动扣款）                    余额不足（记账模式）
        status: approved                       status: approved
        payment: balance_deduct                payment: credit
                                                      │
                ▼                                     ▼
          直接使用                                使用后结算
```

### 场景二：外部访客预订办公室（人工审批 + 预付）

```
选择办公室 → 选择日期 → 选择时段 → 填写信息 → 提交（status: pending）
                                                      │
                                                  管理员审批
                                                      │
                                           ┌──────────┼──────────┐
                                           ▼          ▼          ▼
                                        approved   rejected   要求修改
                                           │
                                       线下付款
                                           │
                                       管理员确认收款
                                           │
                                       status: approved
                                       payment: paid
                                           │
                                         使用 → 完成 → 结算
```

### 场景三：餐饮空间预约（餐次模式）

```
选择包间 → 选择日期 → 选择餐次（午餐/晚餐） → 填写人数
                                                      │
                                          选择餐标（标准/VIP/豪华）
                                                      │
                                          确认费用 = 餐标 × 人数
                                                      │
                                                    提交
```

## 十、系统边界说明

### 当前支持的场景

- ✅ 企业内部办公空间预约管理
- ✅ 会议室小时制预订（含冲突检测）
- ✅ 办公室/工位日/周/月租用
- ✅ 餐饮空间餐次预约
- ✅ 半天/场次/时段预订
- ✅ 自动审批与人工审批双轨
- ✅ 余额实时扣减与记账月结
- ✅ 管理员线下收款确认
- ✅ 月度账单生成与结算

### 当前暂不支持

- ❌ 线上第三方支付（支付宝/微信）集成
- ❌ 实时音视频/物联网设备联动
- ❌ 移动端原生 App
- ❌ 多语言国际化界面
- ❌ 多园区跨地域统一管理
- ❌ 资源冲突自动推荐替代方案（已有备选建议框架）
